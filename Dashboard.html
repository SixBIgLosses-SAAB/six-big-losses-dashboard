จัดการ Part/Model
รายชื่อ Part/Model ที่ใช้ในฟอร์ม "บันทึกยอดผลิตประจำกะ" — จัดกลุ่มอัตโนมัติตามแผนก/ไลน์ที่ผูกไว้ผ่าน Routing (นำเข้าที่หน้า "CT / Routing") Part ที่ยังไม่มี Routing จะอยู่ในกลุ่ม "ยังไม่ผูกแผนก/ไลน์"
➕ เพิ่ม Part/Model ใหม่ด้วยมือ
ใช้สำหรับ Part ที่ยังไม่มี Routing ในระบบ — จะไปอยู่ในกลุ่ม "ยังไม่ผูกแผนก/ไลน์" ก่อน จนกว่าจะ import Routing ผูกกับเครื่องจักรจริง
🎯
ตั้งเป้าหมาย MTBF / MTTR
ตั้งเป้าหมายเพื่อวาดเส้น Target ในกราฟ MTBF vs MTTR พร้อมขึ้น ✅/❌ เทียบผลจริงอัตโนมัติ (อ้างอิงจากฟอร์มรายงาน KPI ฝ่าย Plant Maintenance ได้ เช่น MTBF ≥ 606 ชม., MTTR ≤ 97 นาที — ปัจจุบันเป็น Target ภาพรวมค่าเดียวทั้งระบบ)
ค่านี้คือเวลาทำงานตามแผนต่อ 1 กะ (นาที) เช่น กะละ 8 ชม. = 480 นาที ระบบจะเอาไปคูณกับจำนวนกะที่มีข้อมูลจริงในแต่ละช่วงเวลา เพื่อประมาณ "Planned Production Time" สำหรับคำนวณ Availability% ของ OEE ครับ

สาเหตุ (Cause) ของ Loss ที่เลือก:
🧪
ข้อมูลจำลอง (สำหรับทดสอบ Dashboard)
สร้างข้อมูลสุ่มลง Sheet "Log" โดยตรง (ไม่ผ่านฟอร์มบันทึกข้อมูล) เพื่อดู Dashboard เต็มรูปแบบก่อนใช้งานจริง — ใช้แผนก/ไลน์/เครื่องจักร/กะ และ Loss/Cause ที่ตั้งค่าไว้จริงในระบบ อย่าลืมลบข้อมูลจำลองทิ้งก่อนเริ่มใช้งานจริง
ค่านี้คือจำนวนเหตุการณ์ Loss โดยเฉลี่ย "ต่อเครื่องจักร 1 เครื่อง" ต่อวัน ระบบจะคูณด้วยจำนวนเครื่องจักรที่ตั้งค่าไว้จริงให้อัตโนมัติ เพื่อให้สัดส่วน Loss เทียบกับ Planned Time สมเหตุสมผล ไม่ว่าโรงงานจะมีกี่เครื่องก็ตาม
ระบบจะคำนวณ Loss ย้อนกลับให้ Availability% / Performance% / Quality% แต่ละหมวดใกล้เคียงกัน (รากที่สามของ OEE% ที่ตั้ง) เพื่อคูณกันแล้วได้ OEE% ตามเป้า
ใส่เฉพาะช่องที่ต้องการคุมเอง ช่องที่เว้นว่างไว้จะ auto จากค่า OEE% รวมด้านบน
⚠️ โหมดนี้สร้างข้อมูลครบทุกเครื่องจักร/ทุกกะ/ทุกวัน (ไม่มีวันเว้นกะ) เพื่อให้คำนวณ Planned Time ได้แม่นยำ พร้อมสร้างยอดผลิตประจำกะให้อัตโนมัติ (จำเป็นสำหรับ Quality%) — ผลลัพธ์เป็นค่า "ใกล้เคียง" เป้าหมาย ไม่ใช่ค่าตรงเป๊ะ 100% เพราะมีการปัดเศษนาที/จำนวนชิ้น
ถ้าติ๊กไว้ ระบบจะสุ่มข้อมูลยอดผลิต (ยอดผลิตรวม/ของดี/ของเสีย) ลง Sheet "Production" ให้ครอบคลุมทุกแผนก/ไลน์/เครื่องจักร/กะ ในช่วงวันเดียวกับข้อมูล Log — จำเป็นสำหรับให้การ์ด OEE% คำนวณ Quality% ได้ (ถ้ายังไม่ได้ตั้งค่า Part/Model ไว้ ระบบจะใช้ชื่อ Part ตัวอย่างแทน)
